# Meg Lanches - Cardápio Online

Aplicação web completa de cardápio digital e realização de pedidos via WhatsApp para a **Meg Lanches**.

- **Demonstração / GitHub Pages**: [Acessar Cardápio](https://devsupremoagt.github.io/meg-lanches/)
- Responsivo para smartphones e desktops
- Carrinho com cálculo em tempo real e persistência em LocalStorage
- Seleção de Entrega (Retirada / Delivery com taxa)
- Seleção de Pagamento (PIX / Dinheiro com troco)
- Envio formatado direto para o WhatsApp do estabelecimento
